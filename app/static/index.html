    Connect this cluster
    
    
      
      
    1. Create a garage in the portal. Sign in at
        app.garageai.eu → Offer your GPU
        (new to GarageAI: sign up as an operator).
        Pick vLLM as the runtime, choose a garage name and accept the operator terms.
      2. 
      
    2. Run the command the portal shows on the head node (), in a terminal or over SSH as
        your normal user. It installs NetBird and a small heartbeat, which needs sudo, so the app can't run it for you.
        Where the command says <YOUR_KEY>, put this cluster's API key:
        
      
          
      
        The setup key and register token in the command are one-time secrets for your terminal only:
          this page never asks for them. Paste only the key, with nothing else inside the quotes.
      3. 
      
    3. Offer the model. When the status above shows the mesh and the heartbeat, go to
        My garages → your garage →
        turn on Offer for the model (…). GarageAI runs an acceptance test; the model is
        sold once it passes. The portal shows whether it is live and what it earns.
      4. 
    
    
    
    Run the command again later
      
    For a new register token, use My garages → your garage → New command. That command skips the
        NetBird install and keeps the mesh connection. Only the head node needs GarageAI; the workers need nothing.
    
  
    
  
    
    
    After a model switch
    
    
    Serving now: . The heartbeat reports it to GarageAI within 5 minutes.
      Then turn on Offer for it under My garages;
      the previous model shows as not installed. The portal shows the name buyers use. The gateway uses 95 % of the
      model's context window.
